## 推荐入口

底部卡片整块成为一个按钮，包含头像、显示名称、邮箱省略文本和展开指示。移除固定的 `Sales Professional`：它不是实际权限或套餐。姓名未设置时显示 `AutoTrack account`；头像优先取显示名称首字母，否则取邮箱首字母，最后回退通用用户图标。设计稿中 `Pengyu Wang / PW` 只是姓名示例，不视为已保存资料。

展开菜单展示完整邮箱、`Settings`、分隔线和 `Sign out`。邮箱只展示一次完整值，长地址可换行。Settings 是普通导航项，Sign out 是按钮，使用带图标的低强调危险色；正常退出无需二次确认。顶部保留标题、通知、日期和时间，账号信息集中到侧边栏。

Settings 不加入 Dashboard / Leads / Agenda / Analytics 业务导航列表。它通过账号菜单进入，拟议 URL 为 `/settings`；支持刷新、直接访问和返回上一业务页。账号菜单中 Settings 在当前页有选中态。

## 首版建议范围（均需本次设计确认后才实现）

| 项目 | 建议行为 | 边界 |
| --- | --- | --- |
| 显示名称 | 可编辑，去除首尾空格，1–60 个字符；独立保存区 | 用于账号展示，不改变业务数据或权限；不设置时使用上述回退 |
| 头像 | 根据身份生成首字母 | 不做上传、裁剪或照片存储 |
| 登录邮箱 | 完整、只读显示 | 不提供修改邮箱入口 |
| 登录方式说明 | 说明现有 Password / Email link 两种登录入口 | 不声称用户已配置密码或已验证某个能力 |
| 当前会话退出 | 菜单与 Settings 共用同一行为 | 保持现有 local scope，只退出当前设备/浏览器 |
| 表单反馈 | 未修改不可保存；等待、成功、失败、重试及离开保护 | 失败保留输入，成功才更新卡片姓名/首字母 |

建议只保留一个 Account 页面，按 Profile、Sign-in、Session 三个区块纵向排列。避免单人版出现 Team、Roles、Workspace 切换、Billing 或套餐信息。显示名称需按认证用户持久化；具体选用认证资料字段还是新增资料表，在获准实现后再验证，当前未承诺任何已存在的存储能力。

## 桌面与移动布局

- ≥768px：保留当前 288px 展开 / 96px 折叠宽度。设计稿在对话窗口中按可用宽度适度收紧；实际实现保持项目现有规格。
- 展开：卡片固定在侧栏底部，菜单向上展开；不推动导航或主内容。菜单宽约 288px，碰撞时限制在视口安全边距内。
- 折叠：只留可聚焦头像按钮；hover/focus 提供 Account 提示；点击在右上侧弹出同一个菜单，仍可读完整邮箱及操作。
- <768px：建议顶部左侧 hamburger 打开约 288px、最大 `视口宽度−48px` 的左侧抽屉；主内容使用完整宽度。抽屉底部直接显示身份、Settings、Sign out，避免在抽屉里再叠一层账号弹窗。进入 Settings 后关闭抽屉。
- 手机 Settings：三个区块单列，输入占满可用宽度，保存按钮留在 Profile 区块底部，退出在 Session 区块。邮箱换行；顶部显示页面标题和通知，完整日期时间在窄屏隐藏。内容正常纵向滚动，不做底部悬浮保存条。
- 抽屉可滚动，底部账号区始终可达；低高度/横屏时不硬性挤在固定位置。点击遮罩或 Escape 关闭，焦点回到打开按钮。

## 交互与状态

| 场景 | 行为 |
| --- | --- |
| 点击卡片 / 头像 | 打开或关闭菜单；页面外点击、Escape、导航后关闭 |
| 键盘操作 | 保留明显焦点；Enter/Space 打开；Escape 返回触发器；链接和按钮按顺序 Tab 访问，无悬停专属操作 |
| 进入 Settings | 页标题 Settings，Account menu 的 Settings 选中；页面顶部提供 Back |
| 未修改 | Save changes 和 Cancel 禁用；不出现错误或额外确认 |
| 编辑 | 保存按钮启用；Cancel 恢复原值；空白名/超长名显示字段错误 |
| 保存中 | Saving…，禁用重复提交；保留当前输入；暂缓离开操作直到结果返回 |
| 保存成功 | Saved，更新当前卡片和头像；未保存状态清除 |
| 保存失败 | 内联错误，保留输入并恢复 Save changes，不假装保存成功 |
| 有修改时离开/退出 | 对话框 Stay / Discard changes；取消保留输入和焦点；丢弃后执行原动作。浏览器关闭/刷新实现时使用原生离开提醒 |
| 退出中 | Signing out…，禁止重复点击；未成功前不隐藏身份或跳转 |
| 退出失败 | 保持登录和当前页，在操作附近显示可重试错误 |
| 退出成功 | 转到现有 `/login`；没有额外营销或账户删除动作 |
| 会话过期 | 沿用现有登录重定向，清除前一个身份的展示，不继续保存旧用户资料 |
| 身份加载/缺失 | 通用头像和 Account，不显示旧邮箱；可恢复错误并提供重试，不伪造身份 |

## 设计稿使用与核验边界

同目录 `account-settings-review.html` 为隔离的可交互设计片段，在对话中显示四种视图：桌面展开、桌面折叠、Settings、移动端。可以点击头像菜单、Settings、折叠按钮、Back，编辑/取消/保存姓名，模拟退出，并查看未保存离开对话框。可选的预览调节支持请求成功/失败和通用姓名/示例姓名。

设计稿没有网络、真实身份读取、真实保存、真实退出或数据库访问。演示成功只改变预览状态。原型中的桌面/移动布局和局部交互不代表已实现的应用行为。仅对设计稿做浏览器检查；不运行应用端测试或构建，不部署。

核验结果：已用本机无头 Chrome 检查桌面菜单、折叠头像入口、Settings 导航、姓名保存、未保存离开保护、移动端抽屉和 Escape 关闭；模拟保存失败保留输入，退出失败保留已登录视图。320 / 390 / 768 / 1056px 视口下未发现页面横向溢出，未捕获到 JavaScript 页面错误。已查看桌面、Settings 和手机截图。这里只验证隔离设计预览，不代表真实认证、资料持久化或生产可用性已通过验证。
